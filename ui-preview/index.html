模拟操作

鼠标模拟：按住 Shift + 拖动 = 双指拖动；Shift + 单击 = 双指轻点；Shift + 快速点两下 = 双指双击；普通单击 = 单指轻点。触摸屏可直接用两根手指。

鼠标按住屏幕任意处 0.5 秒 = 长按：出现左右提示后，按住往左/右拖到两侧松手就切页；不拖直接松手 = 歌曲详情（音乐页）。

键盘：↑↓ 切歌，←→ 音量，[ ] 切页，M 静音，空格 播放/暂停，T 背景模式，C 封面显示，D 详情，G 引导。

选"真机尺寸"并按你的显示器选档，屏幕上看到的大小约等于实物（7.4 × 4.9 cm）。
