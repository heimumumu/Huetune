# 声色 Huetune

用微雪 ESP32-S3-Touch-LCD-3.5 控制 Windows 上的音乐。屏幕显示歌名、封面和进度，双指滑动可调音量或切歌。设备设置支持手势反转。

## Windows 一键安装与烧录

1. 用 USB 数据线连接一块微雪 **ESP32-S3-Touch-LCD-3.5（16 MB）**，双击发布包里的 `HuetuneSetup.exe`。
2. 确认安装器识别到开发板后，勾选型号确认框，再点 **一键安装并烧录**。如果原厂固件没有出现串口，按住 **BOOT**，按一下 **RESET**，再松开 **BOOT**。
3. 等待安装器显示两个版本已连接。之后可从 Windows 开始菜单打开 **Huetune**。

安装器内含烧录工具和 Windows 配套程序，无需预装 Python 或 ESP-IDF。已有 Huetune 0.2.3 或更新版本时自动进入下载模式，只更新应用区并保留设备设置。首次烧录或手动进入下载模式时，安装器先备份开发板的 16 MB 闪存。点击安装器的 **备份文件** 或 **安装日志** 可找到对应文件。

如果写入已校验但开发板仍停在下载模式，按一下 **RESET** 再重试。若需要恢复原厂固件，先核对备份的 SHA-256 和文件名里的设备序列号，再用 esptool 5.6.0 在下载模式将该板自己的完整备份写回地址 `0x0`。这个操作会恢复备份里的固件和设置。

## 使用与反馈

从 Windows 开始菜单打开 **Huetune**，随后可在系统托盘查看连接状态。设备设置中的「？」会显示当前模式的手势说明。

欢迎在 Issues 反馈开发板型号、Windows 版本、播放器和问题的复现步骤。上传截图或日志前请移除用户名、文件路径等个人信息。
